# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in GiftBro AI, please report it privately rather than opening a public issue.

You can contact me through the email listed on my GitHub profile.

Please include:
- A description of the vulnerability
- Steps to reproduce it
- Any relevant screenshots or logs
- The potential impact

I’ll review valid reports and work toward addressing confirmed security issues.

## Scope

This policy applies to the GiftBro AI repository and its publicly available code.
